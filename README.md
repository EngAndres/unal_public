# Universidad Nacional de Colombia - Material del curso Programación de Computadores

Bienvenido. Este repositorio contiene el material del curso **Programación de Computadores**, dictado por el profesor Carlos Andrés Sierra, M.Sc., en el Departamento de Ingeniería de Sistemas y Computación de la Facultad de Ingeniería de la Universidad Nacional de Colombia.

## Contenido

El repositorio está organizado en la carpeta `Programacion/`:

```
Programacion/
├── slides/        Diapositivas de clase (01 a 10)
├── project/       Enunciado del proyecto final en LaTeX (Proyecto_Final.tex y PDF)
├── Python básico.ipynb                  Notebook de clase: Python básico
└── Python básico (estudiantes).ipynb    Notebook de clase: Python básico (versión para estudiantes)
```

### Notebooks de Python básico

Notebooks basados en las diapositivas 04 a 10: metodología, tipos de datos y expresiones, funciones, condicionales y ciclos. Existen dos versiones:

- **Python básico.ipynb**: notebook principal del tema.
- **Python básico (estudiantes).ipynb**: versión para estudiantes.

Ambos pueden abrirse en Jupyter o en Google Colab.

### Proyecto final (2026-II)

Enunciado del proyecto **«Simulador de un sistema de ingeniería»**. En grupos de tres integrantes, cada grupo construye un programa en Python que simula un sistema propio de las ingenierías de sus integrantes, usando únicamente los temas vistos en las diapositivas 04 a 10.

Entregables principales:

- Un notebook de Jupyter o Colab con un menú que se repite hasta elegir salir.
- Funciones, cada una en su propia celda y probada justo debajo.
- Un modelo matemático sencillo del sistema, resuelto numéricamente paso a paso y verificado.

Archivos disponibles: `Proyecto_Final.tex` (fuente), `Proyecto_Final.pdf` (documento compilado). Los archivos auxiliares de compilación (`.aux`, `.log`, `.fls`, `.fdb_latexmk`, `.synctex.gz`) son generados por LaTeX y no son necesarios para leer el proyecto.

## Temas del curso

- Metodología de programación: análisis, especificación, diseño, prueba y codificación.
- Tipos de datos y expresiones en Python.
- Funciones.
- Estructuras condicionales.
- Ciclos: mientras, hacer-mientras y para.
- Resolución de problemas y algoritmos.

## Requisitos

- Python 3 (para ejecutar localmente), o una cuenta de Google para usar Google Colab.
- Jupyter Notebook o JupyterLab, si se trabaja de forma local.
